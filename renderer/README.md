# VPipeline Remotion Renderer

## Install

```bash
npm install
```

## Run Remotion Studio

```bash
npm start
```

## Render

```bash
npm run render
```

## Manifest

Replace:

```text
src/data/RendererManifest.json
```

with the manifest generated by VPipeline.

Audio paths in the manifest should be public-relative paths such as:

```json
"/audio/1.wav"
```

Images should similarly use public-relative paths such as:

```json
"/images/example.jpg"
```

The renderer automatically:

- reads the manifest
- calculates the total video duration
- calculates each scene duration
- sequences scenes
- routes scenes by type
- attaches scene audio
- renders the appropriate scene component
