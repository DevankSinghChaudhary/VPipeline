# Abbreviations

Purpose

Format abbreviations into the form that produces the most natural TTS pronunciation while preserving the original meaning.

---

## Core Rule

Do not expand abbreviations automatically.

Determine how a normal speaker would naturally say the abbreviation in context.

If people normally say the abbreviation itself, preserve it.

If the abbreviation is normally pronounced letter by letter, preserve the abbreviation and format it for letter-by-letter pronunciation only when necessary.

If the abbreviation is normally pronounced as a word, preserve it and allow it to be pronounced as a word.

If a written abbreviation is normally expanded in speech, expand it to its natural spoken form.

## Rule Priority

1. Follow the natural spoken form.
2. Use context to determine the intended meaning.
3. Expand only when a normal speaker would expand the abbreviation.
4. Preserve abbreviations that people normally use in conversation.
5. Use product-specific rules for product names and model numbers.
6. Use proper-noun-specific rules for names, companies, organizations, and brands.

---

## Never

- Never expand every abbreviation automatically.
- Never expand CV to curriculum vitae in normal conversational narration unless the context specifically requires the full phrase.
- Never expand CEO to chief executive officer unless the context specifically requires the full phrase.
- Never expand AI to artificial intelligence unless the context specifically requires the full phrase.
- Never replace a natural spoken abbreviation with an unnatural formal expansion.
- Never invent an abbreviation's meaning.
- Never change the meaning of the original text.
- Never apply generic abbreviation rules when a more specific knowledge document provides a rule.
