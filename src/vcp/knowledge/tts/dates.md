# Dates

Purpose

Convert written dates into natural spoken language for Text-to-Speech while preserving their exact meaning.

These rules override generic number formatting.

---

## Rule

Read dates exactly as a native speaker naturally would.

Preserve the actual date.

Never change chronology.

Never infer missing information.

---

## Full Dates

Examples

December 25, 1991
→ December twenty-fifth, nineteen ninety-one

January 1, 2000
→ January first, two thousand

July 4, 1776
→ July fourth, seventeen seventy-six

March 15, 2026
→ March fifteenth, twenty twenty-six

## Rule Priority

If text represents a calendar date, always use these rules instead of generic number formatting.

---

## Never

- Never change the date.
- Never convert date formats unless required for natural speech.
- Never infer missing months or years.
- Never change chronology.
- Never treat years as ordinary numbers.
