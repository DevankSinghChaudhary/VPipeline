# Technical Terms

Purpose

Format technical terms so they are pronounced naturally, clearly, and accurately by Text-to-Speech while preserving their established meaning and domain-specific pronunciation.

---

## Core Principle

Technical terms should be spoken the way people in the relevant field naturally pronounce them.

Do not simplify, expand, or respell a technical term merely because its written form looks unusual.

If a technical term is commonly pronounced in a specific way by professionals, prefer that pronunciation.

---

## Preserve Established Pronunciation

Use the established pronunciation of a technical term.

Examples

Python
→ Python

Linux
→ Linux

Git
→ Git

Docker
→ Docker

Kubernetes
→ Kubernetes

React
→ React

Do not alter technical terms merely to make them look more phonetic.

---

## Context Determines Pronunciation

Some technical terms have different pronunciations depending on context.

Use the surrounding text to determine the intended meaning and pronunciation.

Examples

Java
→ Java, the programming language

Java
→ Java, the island or coffee, depending on context

Rust
→ Rust, the programming language

Rust
→ rust, the material oxidation process

Go
→ Go, the programming language

Go
→ go, the verb

---

## Models and Versions

Do not apply generic number rules to technical model names, software versions, or hardware names.

Examples

RTX 4090
→ follow product-specific pronunciation rules

Python 3.12
→ Python three point twelve

Ubuntu 24.04
→ Ubuntu twenty-four point zero four

Wi-Fi 6
→ Wi-Fi six

USB 3.0
→ U S B three point zero

Use dedicated product, version, or hardware rules when available.

---

## Commands and Code

Do not read source code as if it were normal prose.

Technical commands should be pronounced in a way that preserves their recognizable structure.

Examples

`git commit`
→ git commit

`uv sync`
→ uv sync

`npm install`
→ N P M install

`docker compose up`
→ Docker Compose up

Use context to distinguish between a command being discussed and ordinary words that happen to look like a command.

---

## Technical Names With Mixed Languages

Preserve technical terms as written when the TTS engine can pronounce them correctly.

Example

The researcher used a Fourier transform.

Do not replace technical terms with approximate English spellings merely because they originate from another language.

---

## Domain-Specific Pronunciation

Technical terms may have different pronunciations across fields or communities.

Prefer:

1. The pronunciation established by the relevant domain.
2. The pronunciation used by the surrounding context.
3. A dedicated knowledge rule when available.

Do not assume that the spelling alone determines the pronunciation.

---
